# Семинар № 8. Анализ эффективности алгоритмов

Пять заданий из «Семинар 8-new.pdf». Программа считает основные операции
и проверяет результаты. Доказательства и разбор каждого задания приведены
в отчёте. Проект расположен в одной папке, исходный файл — `main.cpp`.

## Запуск в VS Code и WSL Ubuntu

Распакуйте архив и откройте папку `sem8` в VS Code через WSL Ubuntu.
В терминале, в папке с `CMakeLists.txt`, выполните:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
(cd build && ctest --output-on-failure)
```

Если нужные инструменты отсутствуют, установите их командой
`sudo apt update && sudo apt install build-essential cmake`.

Затем запускайте задания по одному:

```bash
./build/sem8 1
./build/sem8 2
./build/sem8 3
./build/sem8 4
./build/sem8 5
```

## Реализация и проверки

1. Mystery — `sum_squares` и `sum_squares_formula`. Сверяются суммы и
   число умножений, включая n = 1.
2. Secret — `find_range` и `find_range_pairs`. Сверяются размахи и
   сравнения на массивах длины 1, а также чётной и нечётной длины.
3. Enigma — `check_symmetry`. Проверяются симметричная матрица и
   ранний выход при первой несовпадающей паре.
4. MatrixMultiplication — `multiply`. Сверяются элементы произведений
   и числа операций, включая матрицы 1 × 1.
5. Binary — `count_binary_digits`. Проверяются однобитовое число
   и значения с длиной до 64 бит.

Ввод — номер задания. Наборы данных заданы в программе. Например, при
n = 5 для Mystery оба варианта дают 55, а числа умножений равны 5 и 3.
Программа выводит счётчики в терминал. Метка `check OK` подтверждает
проверки выбранного задания. Все пять опытов также зарегистрированы в CTest.

Некорректные аргументы, пустые массивы и матрицы, несовпадающие размеры
и выход из допустимого диапазона передаются исключениями. `main`
печатает сообщение в stderr и возвращает ненулевой код. Для Mystery
ограничение n ≤ 1 000 000 гарантирует представимость промежуточного
произведения формулы в `uint64_t`.

Проверка стиля выполняется командой
`clang-format --dry-run --Werror main.cpp`.
